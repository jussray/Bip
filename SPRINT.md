## Durable sprint rule

Each active mission should carry:

- exact base and head authority;
- one bounded outcome;
- explicit non-goals;
- proof requirements;
- rollback;
- README/document impact;
- one next founder gate.

A sprint handoff is not a release oracle. If `main` or provider state changes, re-pin before continuing.
