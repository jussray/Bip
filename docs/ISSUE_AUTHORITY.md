# Se’kret Bip — Issue Authority

> **Historical snapshot.** The former detailed issue-status inventory is preserved in Git history, but issue open/closed state, PR ownership, and current heads are volatile and must be read from GitHub live.

This file remains only as a durable reminder of the ownership rule: one outcome should have one canonical tracker, while supporting work links to that tracker instead of creating competing authority.

For a current issue decision:

1. search live GitHub issues and PRs for the same outcome;
2. inspect the live state, newest comments, acceptance criteria, and retained evidence;
3. prefer the tracker with the strongest evidence-backed acceptance contract;
4. do not infer completion from duplicate cleanup, a merged supporting PR, or copied prose in an older document;
5. if newer evidence contradicts a former completed state, preserve the earlier observation as history and follow the live reopened/superseded authority.

`docs/TRUTH_AUTHORITY.md` defines the claim lifecycle. Exact-production release evidence is coordinated through issue #696; other issue ownership must be resolved live rather than copied here.
