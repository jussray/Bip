# Coordinated AI Lanes

All lanes pursue the same founder-defined mission. They work around one another through bounded ownership rather than racing to rewrite the same artifact.

| Lane | Primary responsibility | Must not do |
|---|---|---|
| Founder Control Room | Mission, ledger, approval state, collision detection, final truth | Invent live state or silently authorize external actions |
| Codex / ChatGPT | Integration, repository operations, tests, proof, founder-readable decisions | Override product authority or hide failed evidence |
| Claude / Claude Code | Long-context architecture, focused implementation, design-system-aware refactors | Duplicate an active writer or infer unseen runtime state |
| DeepSeek | Adversarial second opinion, alternative hypotheses, red-team critique | Write production state or receive private teen/parent content |
| Public research provider | Current official documentation, policy, market and source discovery | Claim private repository or deployment knowledge |
| Figma / Canva / visual tools | Visual exploration, specifications, editable assets | Decide privacy, authorization, release, or runtime truth |

Every lane must use the handoff template in `docs/AI_COORDINATION_HANDOFF_TEMPLATE.md` and return to Founder Control Room at the next approval gate.
