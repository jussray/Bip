# Multi-AI Handoff Template

Use this exact shape when one AI lane hands work to another.

```text
Mission:
Artifact owner:
Current writer:
Verified repository and branch:
Observed reality:
Requested next lane:
Allowed files or surfaces:
Explicitly excluded data:
Decisions already made:
Open risks:
Evidence references:
Approval state:
Expected output:
Rollback or fallback:
Next founder gate:
```

A handoff is not permission to exceed the listed scope. The receiving lane must re-observe repository truth before acting and must return control to Founder Control Room when the next founder-only gate is reached.
